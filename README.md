# 🐱 Nyako

> **One Search. Every File Task.**

Nyako is a modern, privacy-first file utility platform that helps users complete everyday document and image tasks directly in their browser.

Unlike traditional online tools, Nyako focuses on speed, simplicity, and privacy by processing files locally whenever possible—meaning your files stay on your device.

---

## ✨ Features

### 🖼 Image Tools
- Compress Images
- Resize Images
- Crop Images
- Rotate & Flip
- Convert Image Formats
- Remove Image Background *(Coming Soon)*
- Transparent Signature Maker
- Passport Photo Maker

### 📄 PDF Tools
- Merge PDF
- Split PDF
- Compress PDF
- Rotate PDF
- Extract Pages
- Image to PDF
- PDF to Image

### 🔍 Smart Search
Simply type what you need.

Examples:

- Compress image to 40KB
- Merge PDF
- Make signature transparent
- Passport photo
- PNG to JPG

Nyako automatically suggests the correct tool.

## ⚡ Getting Started

Clone the repository

```bash
git clone https://github.com/garvboiiiii/nyako.git
```

Go into the project

```bash
cd nyako
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
